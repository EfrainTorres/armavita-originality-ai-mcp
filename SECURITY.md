# Security Policy

## Supported Versions

Only the latest release is supported for security updates.

## Reporting a Vulnerability

Please do not open public issues for sensitive security reports.

Preferred options:

1. Open a private GitHub Security Advisory in this repository.
2. If advisories are not enabled yet, contact the maintainer directly and include:
   - impact summary
   - reproduction steps
   - affected version/commit
   - suggested mitigation (if available)

You will receive acknowledgment as soon as possible, followed by triage and remediation planning.
